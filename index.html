🛠️ How to Install in Google Chrome

Since this is an exclusive Hackathon build, it is not on the Chrome Web Store yet. Follow these 4 easy steps to install the developer version:

1
Download & Extract
Click the download button above to get the SentinelAI_Mobile_Extension.zip file. Right-click the downloaded file and select "Extract All...".
2
Open Chrome Extensions
Open Google Chrome, type chrome://extensions/ into your URL bar, and press Enter.
3
Enable Developer Mode
In the top-right corner of the Extensions page, turn on the toggle switch for "Developer mode".
4
Load the Extension
Click the "Load unpacked" button in the top-left corner. Select the folder you extracted in Step 1. SentinelAI is now actively protecting you!
